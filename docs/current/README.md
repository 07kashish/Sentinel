# docs/current — what is true now

This directory distinguishes current program decisions from measured evidence. Generated snapshots name their source commit and artifacts; a newer documentation commit does not upgrade their evidence. Historical reports elsewhere remain available and must be checked against their own dates, scope and provenance.

| File | What it is | How it is kept true |
|---|---|---|
| `STATUS.md` / `.json` | Every known risk with severity, owner, mitigation, the evidence that closes it and a review date | The JSON is the source; the markdown is rendered from it by the same script |
| `DECISION_LOG.md` | Every place the code deliberately departs from fail-closed, with owner, scope, expiry, metric and customer approval | Hand-maintained; a new exception may not ship without a row |
| `INCIDENT_ROTATION_CHECKLIST.md` | What to do the moment a credential is found where it should not be | Hand-maintained |
| `PRODUCTION_ACCEPTANCE.md` | The measurable conditions under which a deployment is accepted, and which are unmet | Hand-maintained; each condition names its evidence artifact |
| `FIRST_WORKFLOW.md` | The approved first workflow and the unverified customer integration gates | Hand-maintained |
| `SECURITY_AND_DR_EVIDENCE.md` | What security and recovery evidence exists, what each proves, and what is missing | Hand-maintained; cites artifacts |
| `PRODUCT_DEFINITION.md` | The adopted business definition of the product, mapped sentence by sentence to what is implemented, its evidence, and what falls short | Hand-maintained; every row names its test or artifact |
| `INTEGRATIONS.md` | Connecting custom GPTs, Bedrock Agents, Azure AI Foundry / Copilot Studio and Vertex AI to Sentinel with one OpenAPI document | The document is generated by `scripts/build_agent_tool_spec.py`; `tests_arch/test_agent_tool_spec.py` fails on drift |
| `DEMO_RUNBOOK.md` | The owner's runbook: preparing and giving the demo, letting people try it, running it for a partner, and what blocks a public launch | Hand-maintained; each command and click was performed at the commit that changed it |
| `TRY_SENTINEL.md` | A tester's guide: the live demo, the device scanner, a one-command local trial, one gated action, the advisory brain | Hand-maintained; each command was run at the commit that changed it |
| `PILOT_KIT.md` | The three-week procedure a design partner follows, with the observation that proves each step | Hand-maintained; every step names its artifact |
| `RELEASE_GOVERNANCE.md` | How a change becomes a release: gates, roles, rollback | Hand-maintained |
| `evidence/external/` | Bound evidence from third parties (none yet) | Same |

## Rules

1. A statement in this directory must be one of: generated from the tree,
   or hand-written with the artifact that supports it named in the same
   sentence.
2. The words *production-ready*, *market-leading*, *compliant*, *secure* and
   *superior to <competitor>* do not appear here as assertions. The generator
   refuses to write `STATUS.md` if they do.
3. When a document elsewhere in `docs/` contradicts one here, verify the underlying code, dated artifact and source commit; neither document wins merely because of its directory.
