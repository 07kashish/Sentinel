# An embedded PostgreSQL server, so the SQL, chaos and concurrency suites run on
# BOTH engines. This is not optional tooling: the predecessor's most subtle

# on one engine cannot see that class of bug.
# macOS: use a same-major local PostgreSQL installation and set
# SENTINEL_TEST_PG_BIN plus SENTINEL_TEST_POSTGRES_DSN; see docs/current/TOPOLOGY.md.
