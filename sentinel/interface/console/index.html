Sentinel

Runtime trust for AI agents. Every consequential action is decided by policy, approved by a person when it should be, executed under a credential that lives for one operation, and recorded as evidence anyone can verify.

Read-only access to a demonstration tenant with sample data. Nothing can be approved, contained or changed.

or sign in with an API token

Use the Sentinel token issued by your administrator for your organisation and role. A Gemini, Google or OpenAI API key will not sign you in. Ask for viewer access to browse or analyst access to decide requests; setup imports require an administrator.

Private sign-in requires HTTPS. This HTTP address supports the public read-only demo only. Ask your administrator for the secure console URL.

Your token is held in this tab’s memory only and is never stored.
